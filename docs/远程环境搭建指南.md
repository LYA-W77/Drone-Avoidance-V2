# 远程环境搭建指南

> 适用于 AirSim v1.8.1 + Unreal Engine 4.27 无人机仿真环境快速部署  
> 适用场景：队友电脑空白，通过远程协助（ToDesk/QQ远程）完成搭建，最终实现 CityPark 城市公园场景下的 Python 控制飞行。

---

## 🖥️ 目标环境

| 项目 | 版本 / 说明 |
| :--- | :--- |
| 操作系统 | Windows 10 / 11 64 位 |
| 游戏引擎 | Unreal Engine 4.27 |
| 集成开发环境 | Visual Studio 2022（需安装“使用C++的桌面开发”工作负载） |
| Python | 3.10.11（**不要使用 3.14 等过高版本**） |
| AirSim 插件 | 1.8.1（已预编译，直接复制） |
| 项目名称 | DroneCityPark（可自定义） |
| 场景 | CityPark Environment Collection（已集成） |

## 📦 前置材料（由已搭好环境的队友提供）

以下材料需通过 ToDesk 文件传输、U 盘或局域网共享发送：

- [ ] 完整的 UE4 项目文件夹（含 `Content` 内所有资源，至少包含 `CityPark`、`StarterContent` 以及蓝图 `BP_AirSimGameMode`、`BP_MyDrone`）

## 第一步：安装基础软件

### 1. Visual Studio 2022

- 下载并运行 VS 2022 安装器，在“工作负载”中勾选 **“使用 C++ 的桌面开发”**。
- 确保右侧已选中 **Windows 10 SDK** 和 **MSVC v142 生成工具**（用于编译 UE4.27 项目）。
- 安装完成后**重启电脑**。

### 2. Unreal Engine 4.27

- 通过 Epic Games Launcher 安装引擎，建议路径 `C:\projects\UE_4.27`。
- 安装完成后运行一次，确认能正常打开。

### 3. Python 3.10.11

- 访问 [Python 3.10.11 下载页](https://www.python.org/downloads/release/python-31011/)，选择 **Windows x86-64 executable installer**。
- 安装时 **务必勾选 “Add Python 3.10 to PATH”**，然后选择“Install Now”。
- 验证：打开命令提示符，执行 `python --version`，应显示 `Python 3.10.11`。

## 第二步：部署项目与插件

### 1. 创建项目目录

```cmd
mkdir C:\projects\DroneCityPark
```

### 2. 放置项目文件

将队友提供的**整个项目文件夹内容**（含 `.uproject`、`Content`、`Config`、`Source` 等）复制到 `C:\projects\DroneCityPark`。

### 3. 放置 AirSim 插件

- 在 `C:\projects\DroneCityPark` 下创建 `Plugins` 文件夹（如果没有）。
- 将队友提供的**整个 AirSim 插件文件夹**（含 `AirSim.uplugin`、`Source`、`AirLib` 等）复制到 `Plugins` 内。

最终路径示例：

```text
C:\projects\DroneCityPark\Plugins\AirSim\AirSim.uplugin
```

### 4. 放置 Python 依赖

- 将队友提供的 `airsim`、`msgpack`、`msgpackrpc`、`tornado` 等文件夹复制到 Python 的 `site-packages` 目录下。
- 查询 `site-packages` 路径：

```cmd
python -c "import site; print(site.getsitepackages())"
```

通常为 `C:\Program Files\Python310\lib\site-packages`。

- 复制完成后，在**管理员命令提示符**中验证：

```cmd
python -c "import airsim; print('导入成功')"
```

### 5. 放置 AirSim 配置文件

在 `C:\Users\<用户名>\Documents\AirSim` 下新建 `settings.json`，内容如下：

```json
{
    "SettingsVersion": 1.2,
    "SimMode": "Multirotor",
    "LocalHostIp": "0.0.0.0",
    "ApiServerPort": 41451,
    "Vehicles": {
        "Drone1": {
            "VehicleType": "SimpleFlight",
            "AutoCreate": true
        }
    }
}
```

> **注意**：文件夹和文件名必须严格一致，扩展名是 `.json` 不是 `.txt`。

### 6. 创建启动快捷方式（解决 `.uproject` 关联问题）

- 在桌面右键 → 新建 → 快捷方式，目标栏输入：

```text
"C:\projects\UE_4.27\Engine\Binaries\Win64\UE4Editor.exe" "C:\projects\DroneCityPark\DroneCityPark.uproject"
```

- 双击该快捷方式即可启动项目。
- 如果出现“项目文件过期”提示，点击 **“是”** 编译。

## 第三步：加载关卡并配置游戏模式

### 1. 编译项目

如果首次启动没有自动编译，手动生成项目文件：

```cmd
"C:\projects\UE_4.27\Engine\Binaries\DotNET\UnrealBuildTool.exe" -projectfiles -project="C:\projects\DroneCityPark\DroneCityPark.uproject" -game -engine
```

然后重新打开项目，等待编译完成。

### 2. 打开 CityPark 关卡

在 UE4 编辑器的**内容浏览器**中，展开 `CityPark` 文件夹 → `Maps`，双击 `Showcase`。

### 3. 设置游戏模式重载

- 菜单栏：**窗口 → 世界设置**。
- 在右侧面板找到 **游戏模式重载 (GameMode Override)**，下拉选择 `BP_AirSimGameMode`。
- 如果下拉列表没有该选项，检查 `Content` 根目录是否存在 `BP_AirSimGameMode.uasset`，并确保项目已编译成功。

### 4. 检查玩家出生点

- 在场景中找到 `Player Start` 物体（小旗杆图标），将其移动到开阔地面，Z 轴位置设为 `100` 左右。
- 如果没有，在内容浏览器搜索 `Player Start` 并拖入场景。

### 5. 保存关卡并设为默认

- `Ctrl + S` 保存关卡（可命名为 `CityPark_Flight`）。
- 菜单：**编辑 → 项目设置 → 地图和模式**，将 **游戏默认地图** 设为刚保存的关卡。

---

## 第四步：运行与测试

### 1. 启动仿真

点击编辑器上方工具栏的 ▶ **运行** 按钮。稍等片刻，无人机应自动出现在 `Player Start` 上空。

### 2. Python 控制测试

- 以**管理员身份**打开命令提示符，切换到控制脚本所在目录。
- 安装键盘监听库（如需）：

```cmd
pip install keyboard
```

- 运行控制脚本：

```cmd
python fly.py
```

- 按下 `K` 键，无人机应起飞；`L` 键降落；`WASD` 控制方向。

### 3. 快速连接验证

在 UE4 运行状态下，另开一个命令提示符，执行：

```cmd
python -c "import airsim; client = airsim.MultirotorClient(); client.confirmConnection(); print('连接成功')"
```

看到 **“连接成功”** 表示整个链路畅通。

## 🩺 常见问题与解决

| 现象 | 原因 | 解决办法 |
| :--- | :--- | :--- |
| 双击 `.uproject` 无法选择 UE4 打开 | 文件关联失败 | 使用快捷方式启动（见上文） |
| 内容浏览器空空如也 | 未复制 `Content` 或缺少初始内容 | 复制完整的 `Content` 文件夹，尤其 `StarterContent`；或在 UE4 中添加“初学者内容包” |
| `GameMode Override` 下拉无 `BP_AirSimGameMode` | 蓝图未编译或未复制 | 确保 `BP_AirSimGameMode.uasset` 存在于 `Content` 根目录，并成功编译项目 |
| 运行时无人机不出现 | `GameMode` 未设置或 `settings.json` 错误 | 检查世界设置中的 `GameMode Override`，以及 `Documents\AirSim\settings.json` 内容 |
| `ModuleNotFoundError: No module named 'airsim'` | Python 环境缺少依赖 | 按前述步骤将 `airsim` 等文件夹复制到 `site-packages`，或重装 `pip install airsim`（需确保 Python 3.10） |
| `ModuleNotFoundError: No module named 'tornado.platform.auto'` | `tornado` 版本不兼容 | 卸载新版，安装 `tornado==4.5.3` |
| 连接时出现 `WSAECONNREFUSED` | AirSim 服务未启动 | 检查是否已点击 UE4 的“运行”按钮，并确认 `GameMode Override` 设置正确 |
| Python 键盘控制无反应 | 未以管理员权限运行脚本 | 右键命令提示符，选择“以管理员身份运行” |

## 📚 附录

### 快捷方式创建方法（备用）

在桌面上新建快捷方式，目标输入：

```text
"C:\projects\UE_4.27\Engine\Binaries\Win64\UE4Editor.exe" "C:\projects\DroneCityPark\DroneCityPark.uproject"
```

名称随意，双击即可打开项目。

### Python 依赖复制的文件夹清单

需复制到 `site-packages` 的文件夹：

- `airsim`
- `msgpack`
- `msgpackrpc`（可能名称为 `msgpack_rpc`）
- `tornado`（务必使用 `4.5.3` 版本）

**获取方法**：在已配置好的电脑上，进入 `python -c "import airsim; print(airsim.__file__)"` 输出的同级目录，找到上述文件夹打包即可。

### 重装 AirSim Python 库（备用）

如果复制文件夹后仍缺依赖，可尝试在管理员命令提示符中执行：

```cmd
pip install --no-build-isolation airsim
```

若失败，先执行：

```cmd
pip install numpy msgpack-rpc-python tornado==4.5.3
```

再执行上述命令。
