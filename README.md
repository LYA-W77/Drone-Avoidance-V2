# Drone-Avoidance-V2

基于 AirSim 的无人机自主避障系统（模块化重构版）。

---

## 🎯 项目简介

本项目实现了一架四旋翼无人机在未知环境中**自主导航与实时避障**的能力。采用**激光雷达为主、距离传感器为辅**的冗余感知方案，通过机体系速度控制实现平滑绕行，并配备了**手动/自动/紧急停止**三种飞行模式。

## 🚀 快速开始

### 1. 环境准备

- 安装 [AirSim](https://github.com/Microsoft/AirSim) 和 Unreal Engine 4.27
- 将 `config/settings.json` 放入 `C:\Users\你的用户名\Documents\AirSim\` 目录下
- 安装 Python 依赖：
  ```bash
  pip install airsim numpy keyboard matplotlib
  ```

### 2. 键盘控制

| 按键 | 功能 |
| :--- | :--- |
| **P** | 切换 自动/手动 模式 |
| **空格 / ESC** | 紧急停止（悬停） |
| **R** | 恢复自动模式 |
| **W / A / S / D** | 手动模式下控制飞行方向（长按） |

## 🧠 核心算法

### 当前主力：加权间隙避障（Weighted Gap Avoidance, WGA）

本算法是一种轻量级、反应式的局部避障方法。它不依赖全局地图，而是实时根据无人机正前方的 5 个扇区距离信息和目标方向，直接生成平滑的飞行速度指令。

**设计目标**：像人一样开车——眼睛盯着目标方向，同时留意左右两侧的空间，哪边宽敞就往哪边靠，不急刹、不漂移。

#### 核心决策逻辑（`decide_action` 函数）

**（1）前向速度（永不驻车）**

- 正前方空旷（距离 > 安全距离）→ 全速巡航（3.0 m/s）
- 正前方逼近障碍物（距离 < 安全距离）→ 线性减速，最低保持 0.8 m/s，确保无人机永远有向前动量，避免“原地卡死”

**（2）侧向速度（加权合成）**

侧向速度由两个因素加权合成（目标方向权重 α = 0.6）：

- **目标吸引分量**：根据目标相对于机头的偏转角度，产生“拉回正轨”的侧向力，保证飞机不跑偏
- **间隙避障分量**：比较左侧（大左+小左）和右侧（小右+大右）的平均距离，哪边更空旷，就往哪边平滑移动

> 通俗理解：**60% 听“导航”（目标方向），40% 看“路况”（左右间隙）**

**（3）低通滤波（防抖）**

对侧向速度指令进行一阶低通滤波，消除传感器噪声和突变，使飞行轨迹如丝般顺滑。

---

### 历史算法：反应式避障（Reactive Avoidance，v1.0）

作为对比基准，`reactive_avoidance.py` 保留了最初的阈值避障逻辑：

- 基于 5 路距离传感器 + 激光雷达点云的扇区最小距离
- 综合考虑“安全距离”和“目标方向”的乘法融合模型
- 连续失败计数器 + 强制脱离机制（后退+上升）
